Reject-rate forecasting and thresholds

+

Forecasts and baselines that helped bring the network reject rate to 4.85% and save about $1M.

Overview

A quarterly forecasting and threshold system for the reject rate across 19 distribution centers, paired with root-cause analysis of each error type.

Problem

Rejects were costly and the causes were scattered across equipment, process and vendor issues, with no shared baseline to manage against.

Approach

Forecast the network reject rate each quarter, set baselines and thresholds for each error type, and led root-cause work on SKU No Reads, Print Failed, Barcode Not in Xref, Unexpected Pack Size and Non-Conveyables.

Result

The network goal tightened from 6.0% to 5.5% to 5.0%. The network averages 4.85% this year, and savings of about $1M were measured against the error-type baselines.

Label defect detection with computer vision

+

A CNN that flags unreadable or misprinted shipping labels before they cause rejects.

Overview

An image classifier that screens photos of printed labels and flags likely failures, inspired by the Print Failed and SKU No Read error types.

Problem

Bad labels are found only after a scan fails downstream, when fixing them is slow and costly.

Approach

Fine-tune a pretrained ResNet on labeled label images with augmentation for blur, glare and skew, set the decision threshold to favor recall, and use Grad-CAM heatmaps to check that the model looks at the barcode area.

Result

On a simulated test set the model reaches 88% recall at 83% precision.
